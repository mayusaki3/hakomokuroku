# ログアウト（POST /api/auth/logout）

本書は、ログアウト API（POST /api/auth/logout）の正式な仕様を定義する。

## 1. 概要

ログイン中のユーザーのセッションを破棄する。
本 API は idempotent（何度実行しても結果が変わらない）とする。

- 認証不要（トークンが既に無効の可能性があるため）
- 成功時は常に { ok: true }
- 例外時のみ { ok: false, error } を返す

## 2. エンドポイント

| メソッド | パス |
|---------|------|
| POST | /api/auth/logout |

## 3. 入力

なし。

## 4. 出力（レスポンス）

### 4.1 成功（常に 200）

```
{ "ok": true }
```

### 4.2 失敗（サーバー内部エラー等）

```
{ "ok": false, "error": "internal error" }
```

## 5. ステータスコード

| 状態 | ステータス | 説明 |
|------|-----------|------|
| 正常終了 | 200 | 常に 200 |
| 内部例外 | 500 | 予期せぬサーバー例外 |

## 6. 挙動仕様

### 6.1 正常ケース
- セッション情報を削除（方式は実装依存）
- セッションがなくても成功扱い
- レスポンスは { ok: true }

### 6.2 エラーケース
- セッション削除処理が例外を投げた場合、500 + { ok:false }

## 7. 例外ケース一覧

| 条件 | 対応 |
|------|------|
| サーバー内部例外 | 500 + { ok:false, error:"internal error" } |

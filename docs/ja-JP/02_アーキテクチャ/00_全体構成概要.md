# 全体構成概要

## 1. 対象
v0.8はVision/LLM画像認識を除く箱目録の完成版とする。v1.0でVision/LLMを追加する。

## 2. 基本構成
- PWA / offline-first。
- Business dataはUser単位で完全分離する。
- local DBは `hk-local-v2-<User.id>`。
- localはBusiness / SyncState / Outboxを分離する。
- server canonical stateと複数端末を通常Syncで収束させる。
- 写真binaryはBusiness JSONと分離して扱う。

## 3. Business entity
- Box
- Item
- BoxLocation

各Userにreserved `UNASSIGNED` Box / BoxLocationを持つ。

関係:
- Item → Box: many-to-one
- Box → BoxLocation: many-to-one
- BoxLocationはBox従属ではなくUser scoped flat master。

## 4. 標準登録フロー
Box → Items → Box photo → Label → Location。

Locationは後決め可能で、新規Boxは原則 `locationId=UNASSIGNED`。

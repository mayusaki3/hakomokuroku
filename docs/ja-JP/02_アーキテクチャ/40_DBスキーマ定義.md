# DBスキーマ定義（Prisma schema）

本書は `apps/web/prisma/schema.prisma` を基に、  
**API仕様とAPIテストケース作成に必要なスキーマ情報**だけを整理した技術ドキュメントである。

最終目的は以下の 2 点：

1. 各 API がどのモデルのどのフィールドを参照/更新するのかを明確化する  
2. API テストケースが「どの状態を前提とすべきか」判断できる状態にする

---

## 1. スキーマ全体構成

本サービスは、以下の領域を DB で管理する：

| 区分 | モデル | 役割 |
|------|--------|-------|
| 認証 | User / SyncToken | ログイン、セッション管理、TOTP、アカウント情報 |
| TOTP | User（内部フィールド） | TOTP 設定・認証フロー |
| ユーザー設定 | UserSetting | Vision設定、UI設定 |
| テーマ | Theme / ThemeActive | カスタムテーマ管理 |
| 箱 | Box / BoxLocation | 箱と場所情報 |
| アイテム | Item | 箱に属するアイテム |
| タグ | Tag | アイテム・箱のカテゴリ付与 |

APIテスト範囲では **認証 / ユーザー情報 / テーマ設定** 部分が主対象である。

## 3. 各モデル詳細（APIテスト観点）

以下は Prisma モデルを API が利用する順で整理したものであり、  
内部フィールドを含む **APIテストで利用される実質的スキーマ**を表す。

---

# 3.1 User（認証・TOTP・表示名・アイコンの中核）

## 役割
- 認証（email/password）
- TOTP 状態管理
- ユーザー表示名・アイコン
- アカウントの有効/ロック

## 主フィールド（抜粋）

| フィールド | 型 | 説明 |
|-----------|----|------|
| id | String (PK) | cuid() |
| userId | String | ログイン用 ID（APIでは email と表現される） |
| userName | String? | 表示名（/api/settings/user） |
| passwordHash | String | パスワードハッシュ |
| iconDataUrl | String? | data URL形式のユーザーアイコン |
| isActive | Boolean | アカウント有効/無効 |

### ■ TOTP 管理フィールド

| フィールド | 説明 |
|------------|------|
| totpEnabled | TOTP が有効化されているか |
| totpSecretEnc | 有効化済み TOTP 秘密鍵（暗号化） |
| totpPendingSecretEnc | セットアップ中の一時秘密鍵 |
| totpPendingAt | 一時鍵の発行時刻（タイムアウト判定） |
| recoveryCodes | 復旧コード（JSON） |
| totpFailCount | TOTP 連続失敗回数 |
| lockUntil | ロックされている場合、その解除時刻 |

### ■ 監査系

| フィールド | 説明 |
|------------|------|
| lastLoginAt | 最終ログイン日時 |
| createdAt / updatedAt | レコード生成・更新日時 |

### ■ リレーション
- tokens: SyncToken[]
- themes: Theme[]
- setting: UserSetting?
- boxes / items / locations / tags: 将来の箱目録機能向け

---

# 3.2 SyncToken（セッション/アクセストークン）

| フィールド | 説明 |
|------------|------|
| id | cuid() |
| userId | User への外部キー |
| token | 実際に Cookie / 認証で使われるトークン |
| kind | access / refresh 等 |
| expiresAt | 有効期限 |
| createdAt / updatedAt | 生成・更新時刻 |

### APIテスト利用箇所
- `/api/auth/login` 正常時に新規生成される
- `/api/auth/logout` で削除される
- `/api/auth/me` で参照される

---

# 3.3 Theme / ThemeActive（テーマ表示状態）

### Theme（ユーザー個別テーマ）

| フィールド | 説明 |
|------------|------|
| id | テーマID |
| userId | 所有者 |
| name | テーマ名 |
| vars | CSS変数セット（JSON） |
| wallpaperThumb | 壁紙サムネイル |
| createdAt / updatedAt | 作成・更新日時 |

### ThemeActive（どのテーマを表示するか）

| フィールド | 説明 |
|------------|------|
| userId | PK |
| themeId | 有効テーマID（null=デフォルト） |
| vars | 最終反映された CSS 変数 |
| updatedAt | 更新日時 |

### API テスト利用箇所
- `/api/settings/theme/active`  
  - ThemeActive + 参照する Theme の整合性確認

---

# 3.5 Box / Item / BoxLocation / Tag（箱目録基盤）

箱目録 API が実装されるまでの準備情報として要点のみ記載。

## Box
| フィールド | 説明 |
|------------|------|
| id | 箱ID |
| userId | 所有者 |
| code | ユーザー内一意の箱コード |
| name | 箱名 |
| meta / thumbs | 将来の AI メタ情報 |
| createdAt / updatedAt | 時刻 |

## Item
| フィールド | 説明 |
|------------|------|
| id | アイテムID |
| userId | 所有者 |
| boxId | 所属する箱 |
| name / note / tags / thumbs | 属性 |

## BoxLocation
| フィールド | 説明 |
|------------|------|
| id | ロケーションID |
| boxId | 対象箱（unique） |
| note / thumbs | 場所情報 |

## Tag
| フィールド | 説明 |
|------------|------|
| id | タグID |
| userId | ユーザー固有 or null = 共有 |
| name | タグ名 |
| kind | TagKind |

# 4. APIテスト設計との関連

APIテストでは **状態遷移** が最も重要。

以下のフィールドは特に依存度が高い：

## 認証（User + SyncToken）
- userId / passwordHash / isActive  
- totpEnabled / totpPendingSecretEnc / totpSecretEnc  
- totpFailCount / lockUntil  
- SyncToken.token / expiresAt

## ユーザー情報
- userName / iconDataUrl

## テーマ
- ThemeActive.themeId / vars  
- Theme.vars と整合性
